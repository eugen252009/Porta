# Generic Agent Harness

A domain-neutral, capability-based harness with a small microkernel, stable contracts, explicit composition, and replaceable adapters.

The initial foundation is headless. It includes runtime-validated contracts, capability resolution, plugin lifecycle primitives, session orchestration, cancellation and deadlines, canonical errors, and deterministic in-memory adapters.

Run `npm install`, then `npm test`, `npm run typecheck`, and `npm run build`.
